Cuestionario de Desarrollo Web

Este documento presenta conceptos clave del desarrollo web y ejemplos de etiquetas HTML.

Frontend y Backend

Frontend: Hace referencia a la interfaz de usuario y la experiencia visual. Es lo que corre directamente en el navegador del cliente.

Backend: Corresponde a la infraestructura del servidor. Procesa peticiones, administra bases de datos y gestiona la lógica de negocio.

¿Qué es HTML5?

HTML5 define la estructura base de los sitios web mediante etiquetas. También permite incorporar contenido multimedia y elementos semánticos.

Ejemplo de etiquetas semánticas: <main>, <article> y <aside>.

Tecnologías esenciales en Frontend

HTML5: define la estructura.

CSS3: aporta estilos, colores y diseño adaptable.

JavaScript: añade dinamismo e interactividad.

Vue.js / React: permiten construir interfaces por componentes.

Tailwind CSS / Sass: facilitan la creación de estilos.

Ejemplos de etiquetas HTML del cuestionario

Estructura básica

<!DOCTYPE html> declara el tipo de documento HTML5.

<html lang="es" dir="ltr"> contiene el documento.

<head> contiene metadatos y enlaces a recursos.

<title> establece el título de la pestaña del navegador.

<meta> define metadatos, como la codificación y el viewport.

<link> vincula recursos externos, como una hoja de estilos.

<body> contiene el contenido visible de la página.

Contenido semántico y texto

<main> identifica el contenido principal.

<article> representa contenido independiente, como una noticia.

<aside> contiene información secundaria o relacionada.

<h1>, <h2> y <h3> representan encabezados de distintos niveles.

<p> crea un párrafo.

<mark> resalta texto.

<strong> indica importancia; normalmente se muestra en negrita.

<em> aplica énfasis; normalmente se muestra en cursiva.

<hr> crea una separación temática.
